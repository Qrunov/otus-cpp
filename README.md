All options:
  -I [ --include-path ] arg  directory search list
  -E [ --exclude-path ] arg  directory search black list(don't search there)
  -L [ --level ] arg         restrict deep of directory search(0 - don't search
                             in subdir's)
  -F [ --filenames ] arg     file masks available for comparision
  -S [ --bsize ] arg (=4096) read block size(byte)
  --alg arg (=crc32)         hash algorithms(crc32, md5)
  -H [ --help ]              produce help message
